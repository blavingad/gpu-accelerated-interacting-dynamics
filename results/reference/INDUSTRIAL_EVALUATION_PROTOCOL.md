# Prospective departmental evaluation

Purpose: test whether digital raster development reduces time and cost while meeting the same printer acceptance criteria. This is a proposed evaluation, not an assertion of realized savings.

1. Predeclare a development brief: device/ink envelope, target font, print height, speed, DPI, clearance, allowed controller representation and independently assessed print-quality policy.
2. Compare the existing rig-based process and the digital workflow on equivalent briefs. Include easy, dense-interaction and genuinely new-structure tasks. Avoid choosing tasks after seeing which method succeeds.
3. Count model construction and physical calibration as setup cost. Count all failed candidates, engineering intervention, computation, table export, metrology and final printer qualification as per-design cost. Record wall time and engineer-hours separately.
4. Freeze commands before independent printer assessment. Preserve extraction/calibration records, repeated prints of the same glyphs, matching identities and measurement uncertainty. A computationally ideal print is not the acceptance label.
5. Report time to an accepted table, rig occupancy, engineer-hours, ink/substrate consumption, computational resource use, acceptance rate, redesign count and robustness across operating conditions. Report both setup-inclusive and amortized costs over subsequent programs.
6. Apply the same accounting to printhead geometry changes. Include new field generation and model reassessment; do not assume a calibrated closure transfers unchanged to a new head.

With setup cost S, baseline per-design cost B and digital per-design cost D, break-even reuse count is S/(B-D) only when B>D. Use measured ranges and uncertainty rather than a single assumed financial return. No numerical saving or payback is claimed before this study is run.
